# Security Policy

## Project Overview

The Empathetic AI Emotional Insight System is an
academic project developed at Rangsit University
using Python, FastAPI, and the Gemini API.

## Supported Versions

Security reports are accepted for the latest
version of the project on the default branch.
Older versions are not actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please
use GitHub's private vulnerability reporting
feature under the Security and quality tab.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The affected component.
- Potential security impact.

Do not publicly disclose unresolved vulnerabilities
or include sensitive credentials in your report.

## Security Practices

This project uses GitHub security features,
including:

- Dependabot alerts and security updates.
- Dependency graph.
- Secret scanning.
- Push protection.
- Private vulnerability reporting.

API keys and other sensitive information should
never be committed to the repository.

## Responsible Disclosure

Security reports will be reviewed as resources
permit. As this is an academic project, immediate
responses and fixes cannot be guaranteed.

Thank you for helping improve the security of
this project.
